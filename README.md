# Titanic Data Analysis

This project is part of my Data Analysis using Pandas, Matplotlib, and Seaborn.

## Topics Covered

- Loading datasets with Pandas
- Exploring data
- Handling missing values
- Data cleaning
- Survival analysis
- Visualization using Seaborn
- Bonus exploratory data analysis

## Visualizations

- Survival Count
- Survival by Gender
- Survival by Passenger Class
- Age Distribution
- Fare Distribution
- Survival Rate by Age Group
- Fare Distribution for Survivors vs Non-Survivors

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
